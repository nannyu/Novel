# 历史类作品存放区

本文件夹用于存放**你认可的历史类短文作品**，作为 Skill 持续学习和优化的素材。

## 重要规则

**优先收录你本人写的、或你认可并希望模仿的历史类短文。**

如果是 AI 生成的内容，必须是你亲自调教、反复修改后认为"这就是我想要的效果"的版本，而不是随便生成的初稿。

## 使用方式

1. **添加新作品**：将作品以 `.md` 格式保存到此文件夹
2. **命名建议**：`YYYY-MM-DD-主题.md`，如 `2026-01-29-柴荣北伐.md`
3. **触发学习**：当积累了 3-5 篇作品后，告诉 AI："学习 history-writer 的新作品并更新 Skill"

## 学习触发条件

当用户说出以下任意一种话时，应触发学习流程：

- "学习 history-writer 的新作品"
- "更新 history-writer Skill"
- "帮我优化历史类内容的写法"
- "根据 samples 文件夹里的作品更新 Skill"

## 学习时 AI 会做什么

1. 读取 `samples/` 文件夹里的所有 `.md` 文件
2. 分析这些作品的共性特征，包括：
   - 开场方式（如何定调、用什么词）
   - 叙述节奏（短句/长句、转折词选择）
   - 判断风格（立场句怎么下、理由怎么给）
   - 收尾方式（如何升华、是否用反问）
   - 避免的写法（哪些表达被刻意回避）
3. 对比现有 SKILL.md 的规则，找出需要新增或调整的点
4. 更新 SKILL.md 中的风格要求、写法要点、示例等
5. 更新本 README 的"当前状态"
