# 数据分析看板

这是一个本地运行的数据分析看板，用来导入公众号或小红书导出的数据文件，并自动生成指标卡片、趋势图、排行图和明细表。

数据只会保存在当前浏览器本地，不会上传到服务器。

## 支持的数据

当前支持导入：

- 公众号数据：`.csv`、`.xls`、`.xlsx`
- 小红书数据：`.csv`、`.xls`、`.xlsx`

公众号推荐导入完整的已发表内容明细。下载路径：

```text
公众号后台（mp.weixin.qq.com）
数据分析
内容分析
已发表内容
已通知内容
下载数据明细
```

如果导入的是公众号趋势表一类的文件，系统可能可以识别出部分文章标题和阅读数据，但字段不完整。此时会先导入成功，再弹窗提示字段不全；字段不全会影响分享人数、送达人数、阅读完成率、内容链接等指标的展示效果。

小红书推荐导入笔记列表明细表，表头通常包含：

```text
笔记标题、首次发布时间、体裁、曝光、观看量、封面点击率、点赞、评论、收藏、涨粉、分享、人均观看时长
```

## 本地运行

先安装：

- Node.js：https://nodejs.org/
- Git：https://git-scm.com/

下载项目：

```bash
git clone 你的 GitHub 仓库地址
cd shujukanban
```

安装依赖：

```bash
npm install
```

启动项目：

```bash
npm run dev
```

终端会显示本地访问地址，通常是：

```text
http://localhost:5173
```

如果 5173 端口被占用，Vite 会自动换成 5174、5175 等端口，以终端显示为准。

## 使用方法

1. 打开本地访问地址。
2. 选择公众号或小红书看板。
3. 点击“导入公众号文件”或“导入小红书文件”。
4. 选择 `.csv`、`.xls` 或 `.xlsx` 数据文件。
5. 看板会自动识别平台并展示数据。

导入后的数据会保存在当前浏览器本地。下次用同一个浏览器打开时，会恢复上次导入的数据。

## 更新项目

如果作者更新了代码，进入项目目录后执行：

```bash
git pull
npm install
npm run dev
```

`npm install` 用来同步新增或变化的依赖，更新后执行一次最省心。

## 常见问题

### 导入后提示字段不全怎么办？

说明这个文件里有部分可识别的数据，但不是完整明细。公众号请重新到下面的位置下载完整明细：

```text
公众号后台（mp.weixin.qq.com）- 数据分析 - 内容分析 - 已发表内容 - 已通知内容 - 下载数据明细
```

### 导入后没有数据怎么办？

请确认文件是公众号或小红书后台导出的数据明细，并且表头没有被手动删除或大幅修改。

### 数据会上传吗？

不会。数据只存储在当前浏览器的本地存储中。

### 如何清空已导入的数据？

可以在浏览器里清除当前站点的本地数据，或者换一个浏览器打开项目。
